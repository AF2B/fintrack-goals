# fintrack-goals

FinTrack microservice for financial goals and budget envelopes.

**Source code and issue tracker live on GitLab:**
[https://gitlab.com/andre.borbaaf2b/fintrack-goals](https://gitlab.com/andre.borbaaf2b/fintrack-goals)

This repository is an anchor only — it mirrors releases and points to the
actual codebase. It is not meant to be cloned for development.

## Releases

Tagged `v1`, `v2`, `v3`, … matching the GitLab releases, each with a
Docker image and/or downloadable artifact linked from the GitLab release
